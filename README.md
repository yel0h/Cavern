# Cavern
Cavern is a simple voxel sandbox game written in C++ using OpenGL shaders.

<img width="802" height="632" alt="image" src="https://github.com/user-attachments/assets/29e08ca1-e16b-4d1f-9d79-c5e7283a1318" />

## Controls
- WASD to move around
- Space to jump
- Mouse to look around
- R to respawn
- Right click to place blocks
- Left click to destroy blocks
- Enter to save world
- 1-4 to select a block
- G to spawn a Wanderer
- F11 to toggle fullscreen

## Technical Details
The world is saved in the world.dat file, either manually (see Controls) or automatically upon exiting the game.
